# 测试 Agent 接入与交接清单

> 用途：为品牌人像判官的独立测试实例建立可复现、可回收、与正式环境隔离的验证环境。
> 当前状态：清单已准备，具体 Bot、权限和运行位置待耿梦桥确认。

## 1. 双方需要准备什么

### 耿梦桥提供

- [ ] 独立测试 Bot 的名称和访问入口；确认不是正式业务 Bot。
- [ ] 测试知识空间、目录和专用测试文档。
- [ ] 能完成新建、修改、移动/删除和撤权测试的管理员或等效权限。
- [ ] Bot 当前已绑定的知识范围、Owner 和管理员名单。
- [ ] Bot 是否配置“每次重新读取”“知识刷新”、周任务或其他定时任务；提供触发规则和最近一次触发时间。
- [ ] 测试完成后的权限回收负责人和处理方式。

不通过聊天或 Git 传递 Token、Cookie、API Key、`.env` 和真实 `agent-sync.yaml`。如需授权，由环境负责人在本机或飞书授权页完成。

### 高佳提供

- [x] GitHub 仓库：<https://github.com/gaojia840303/lark-agent-knowledge-sync>
- [x] [首轮双验证执行方案](首轮双验证执行方案.md)
- [x] [MVP 运行说明](MVP运行说明.md)
- [x] 配置模板：`agent-sync.example.yaml`
- [ ] 本次使用的分支和 Commit：执行前填写。
- [ ] 3—5 份会议材料清单、授权证据和预期标签。
- [ ] 本次运行位置和执行人：待双方确认。

## 2. 运行位置只选一种

| 方案 | 适用条件 | 责任边界 |
|---|---|---|
| 高佳环境运行 | 高佳账号已具备测试来源和目标的最小权限 | 耿梦桥只提供测试 Bot/目录；高佳保管本地配置并执行 |
| 耿梦桥环境运行 | 权限不能授予高佳，或 Bot 只能在其环境管理 | 高佳提供仓库和步骤；耿梦桥本地授权并执行，高佳读取脱敏结果 |

不得为了省事把真实凭证提交到仓库，也不得使用正式 Bot 代替独立测试实例。运行位置确认后，把选择和原因写入本清单，不同时维护两套分叉代码。

## 5. 接入验收

- [ ] 测试 Bot、知识目录和材料来源均与正式环境隔离。
- [ ] 能明确区分平台原生索引、Bot 问答时重新读取和已有定时任务。
- [ ] `validate-config --strict` 通过。
- [ ] `scan --dry-run` 的实际来源只包含已批准的 3—5 份材料。
- [ ] 目标知识目录、目标文档和未经授权个人文档读取数为 0。
- [ ] 未在日志、截图、Git 或共享文档中泄露凭证。
- [ ] 已约定测试结束后的权限回收和资料保留方式。
