## 2. 三阶段不要混用

| 阶段 | 样本与目的 | 通过后进入 |
|---|---|---|
| A. 首轮功能验证 | 3—5 份真实会议材料，确认范围校验、候选识别、拒绝、审核和幂等链路可工作 | 扩充正式评测集 |
| B. 正式质量评测 | 不少于 10 条正例，并覆盖反例、边界、冲突和替代样例，测发现率和提案质量 | 隔离单 Agent 连续运行 |
| C. 业务效果评测 | 对比品牌人像判官更新前后的真实输出质量、人工修改量或完成时间 | 决定是否生产启用和扩大范围 |

评测集与 Skill 可以共用样本编号、预期标签和结果表，但不能合并成同一个实现：Skill 是被测系统，评测集是独立验收依据。修改 Skill 后不得顺手修改预期答案来让测试通过。

## 4. 正式质量评测集

功能链路通过后，把首轮真实样本中可复用的条目固化，再补齐正式评测集：

- 正例不少于 10 条。正例是“按 Agent 职责和来源授权，本来就应该被发现并形成正确候选”的内容。
- 反例必须包含明显无关内容和不稳定动态状态。
- 边界样例必须包含权限不足、范围外来源、目标知识自循环和证据不足。
- 冲突样例必须包含新旧说法不一致、多人意见未定或权威等级不同。
- 替代样例必须包含新规则明确替换旧规则，并要求保留版本和来源关系。

| 样例ID | 类型 | 来源 | 预期发现 | 预期知识/拒绝理由 | 预期权限与范围 | 实际结果 | 证据 |
|---|---|---|---|---|---|---|---|
| 待填写 | 正例/反例/边界/冲突/替代 | 待填写 | 是/否/标记冲突 | 待填写 | 待填写 | 待测试 | 待填写 |

评测集版本必须与 Git Commit、Agent 配置版本一同记录。预期答案变更须由业务审核人说明原因，不能由实现者单方修改。

## 5. 失败分类

每个失败必须归入一种主因，避免用“模型不准”笼统解释：

- `source_missing`：正确来源未纳入或已撤权。
- `scope_rejected`：被目录、人员、视图或授权边界拒绝。
- `metadata_missed`：来源存在，但低成本筛选未发现变化。
- `relevance_false_negative`：应相关却被规则或模型排除。
- `relevance_false_positive`：无关内容进入候选。
- `authority_error`：来源权威等级或适用范围判断错误。
- `version_conflict`：旧规则、替代或冲突未正确识别。
- `extraction_error`：事实、结论或推断混淆。
- `review_rejected`：审核人认为不应沉淀。
- `apply_or_index_error`：批准后写入或知识库生效失败。

## 6. 指标与门槛

### 首轮功能验证门槛

| 指标 | 门槛 |
|---|---:|
| 未授权个人文档、目标目录或目标文档读取 | 0 |
| 未经审核自动写正式知识 | 0 |
| 动态状态、未确认讨论被当作正式知识 | 0 |
| 相同输入第二次运行的重复提案 | 0 |
| 读取范围、预算、候选和拒绝原因可追溯 | 100% |
| 明显相关/无关/冲突样本是否按预期处理 | 逐条人工判定，不用小样本百分比冒充统计结论 |

### 正式质量评测门槛

| 指标 | MVP 门槛 |
|---|---:|
| 预期正例发现率 | 不低于 80% |
| 首轮批准或仅需小修改 | 不低于 60% |
| 未授权个人文档/目标知识读取 | 0 |
| 动态状态、草稿、未确认讨论进入长期知识 | 0 |
| 相同增量第二次运行的重复提案 | 0 |
| 权威等级和目标范围严重错误 | 0 |
| 单次运行超出批准硬预算 | 0；必须停止并记录原因 |
| 审核意见可追溯率 | 100% |

同时记录耗时、来源 API 调用、正文字符、候选和提案数量。Token 指标只有模型实际启用后才记录，未启用不能填写为 0 并视为通过。

## 9. 放行规则

- Phase 0 可与首轮功能验证并行，但生产启用前必须有明确结论。
- 先用 `scan --dry-run` 验证零写入、来源范围和非模型预算，再在隔离审核仓生成提案。
- 首轮 3—5 份材料只用于发现问题和验证链路，不用小样本百分比宣布质量达标。
- 正式评测集通过后，再连续运行 2—3 个真实周期；所有安全指标为 0 且质量门槛达标，才进入正式单 Agent 运行。
- 任一越权读取、目标自循环、严重权威错误或预算无法停止，立即退回配置/代码修复，不通过扩大来源或放宽阈值补偿。
- 只有功能和质量验证通过后，才开展业务效果评测；只有单 Agent 通过后，才评估生产调度、多 Agent、共享缓存和模型自动提炼。
