# 项目背景

本项目来源于 AI 提效团队对“业务 Agent 如何持续获得最新知识”的讨论。

现有业务 Agent 已经可以读取飞书知识并回答问题。对于已绑定知识库中的新增、修改和删除，平台是否会自动、及时更新 Agent 的检索结果，目前仍需通过实际测试确认。

项目因此分成两个问题：先验证知识库平台自身的绑定与索引能力；再针对会议、Meegle、Base 和上游文档等知识库外部来源，建设一份全局维护、按 Agent 配置运行的知识同步 Skill，使多个业务 Agent 复用同一套增量采集、筛选、审核和沉淀流程。

项目不建设新的问答检索链路，也不建设一个替代全部业务 Agent 的中央知识 Agent。如果三项知识库验证通过，正式知识库内部的普通人工编辑不进入同步 Skill。动态状态继续以 Base 和 Meegle 为权威来源；只有尚未进入目标知识库的稳定事实、决策、规则、流程和复盘结论才进入知识沉淀流程。

详细架构与实施阶段见 [Agent 自动更新能力落地方案（修订版）](Agent自动更新能力落地方案.md)。
