# 项目背景

本项目来源于 AI 提效团队对“业务 Agent 如何持续获得最新知识”的讨论。

现有业务 Agent 已经可以读取飞书知识并回答问题，但知识本身仍依赖人工维护。当会议形成新决策、文档发生修订、Base 数据结构变化或 Meegle 项目完成复盘后，相关知识无法稳定、及时地进入各 Agent 的知识范围。

项目因此聚焦一个明确目标：建设一份全局维护、按 Agent 配置运行的知识同步 Skill，使每个业务 Agent 都能复用同一套增量采集、筛选、审核和沉淀流程。

项目不建设新的问答检索链路，也不建设一个替代全部业务 Agent 的中央知识 Agent。动态状态继续以 Base 和 Meegle 为权威来源；只有稳定事实、决策、规则、流程和复盘结论才进入长期知识。

详细架构与实施阶段见 [Agent 自动更新能力落地方案（修订版）](Agent自动更新能力落地方案.md)。
