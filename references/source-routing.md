# 来源路由

## 来源准入优先级

上游来源按以下优先级进入知识候选流程：

1. **主动投递**：人员提交来源链接、将文档放入“待沉淀”共享目录，或添加约定状态与标签。
2. **专用业务视图**：Base、Meegle 中的“已确认决策”“已完成复盘”“待沉淀知识”等窄视图或 MQL。
3. **受限增量扫描**：明确配置的会议系列、共享目录、项目、人员和关键词。
4. **默认排除**：公司全空间、整项目、个人云空间、临时草稿、聊天噪音和未授权内容。

个人文档只有主动提交、进入指定共享目录或被业务负责人明确批准时才能进入。不得因为运行身份拥有读取权限，就把所有可见内容视为业务授权来源。

## 目标知识库与上游来源

- `knowledge.public_document_token` 和 `knowledge.private_document_token` 是正式知识写入目标，不是上游采集来源。
- `sources.documents` 只配置尚未进入目标知识库的上游文档或限定目录。
- 目标文档 Token 不得同时出现在 `sources.documents.document_tokens` 中，避免扫描、提案、写回形成自循环。
- 目标知识库中的普通人工新增、修改和删除沿用知识库平台索引与飞书版本历史，不进入审核表或游标表。
- 首次实施前必须完成新增、修改、删除三项知识库绑定行为验证；如果验证失败，应建立索引、绑定、缓存或权限问题，不用知识沉淀流程补偿。
- 目标知识库验证通过后，还必须完成上游采集范围与成本验证；通过不代表可以扫描全部飞书内容。

## 动态事实

以下内容默认保留在权威数据库，不复制进长期知识：

- Meegle 的状态、负责人、排期、任务进度和节点信息。
- Base 中持续变化的业务记录和统计结果。
- 临时待办、未确认讨论和执行日志。

动态来源默认在 Agent 使用时实时查询，不进入周期知识扫描。只有确有运行摘要需求并已限定窄视图时才参与增量检查；只有专用视图或 MQL 显式配置 `knowledge_mode: stable` 才生成审核候选。

## 稳定知识

以下内容可以生成审核候选：

- 会议确认的决策、规则和责任边界。
- 品牌、产品方法论和统一口径。
- 可复用流程、模板使用规则和字段关系。
- 已完成复盘的验证结论。
- 对旧规则的明确替换或废止决定。
- 尚未进入目标知识库的上游方法、决策和复盘结论。

## 公共与专属

- `target_scope: public`：公司级规则、跨 Agent 通用方法、公共术语。始终高风险并要求人工审核。
- `target_scope: private`：单个品牌、产品或 Agent 的专属知识。MVP 仍需人工审核。
- 目标文档只从 `knowledge.public_document_token` 或 `knowledge.private_document_token` 读取。
- 不允许模型或来源正文提供目标 Token。

## 相关性顺序

1. 来源必须位于配置白名单。
2. 来源必须满足准入类型：主动投递、专用业务视图或受限增量扫描。
3. 先检查事件、更新时间、目录、人员、项目、状态等元数据，不通过时不读取正文。
4. 命中排除词立即拒绝。
5. 命中包含词、相关人员或相关项目后，才允许进入正文与语义判断阶段。
6. 搜索型来源没有任何相关性规则时拒绝运行；只有主动提交的明确 Token 或经批准的专用视图可以把来源本身作为相关性证据。
7. 保存来源准入方式、命中规则和筛选理由作为审核证据。

## 低成本处理漏斗

```text
来源白名单
→ 来源侧新增/修改
→ 元数据与业务规则
→ 正文按需读取
→ 内容哈希去重
→ 少量候选进入模型
→ 审核提案
```

- 不允许为了语义判断先读取公司范围内的全部正文。
- 会议先使用标题、参与人、项目和摘要，只有必要时读取逐字稿。
- 长文优先处理摘要、章节或变更段落，不重复提交未变化全文。
- 达到单次运行预算后停止并顺延，不自动扩大来源或预算。

## 多 Agent 共享来源

首个 MVP 可以在严格小范围内按 Agent 独立采集。进入多 Agent 阶段后，相同会议、文档或记录应采集一次、按来源 ID 和内容哈希缓存，再依据各 Agent 规则分别路由。共享采集层只保存来源事实和变更状态，不代替业务 Agent 做知识判断，也不能跨越各 Agent 的权限边界。

## 当前实现边界

当前 V2 部分来源仍会先读取正文或分页数据，再做批次哈希与规则筛选；同步脚本尚未调用模型，也没有单次总量与 Token 硬预算或共享采集缓存。上述漏斗是目标架构，现阶段只能在隔离、小范围配置中验证，不能描述为已经具备公司级处理能力。
