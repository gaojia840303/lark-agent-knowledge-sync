# Claude 兼容适配

不复制、不改写公共同步逻辑。Claude 运行环境只做一层命令适配：

1. 将全局 Skill 目录以只读依赖方式提供给执行环境。
2. 传入与 Codex 完全相同的 `agent-sync.yaml`，保证来源范围、个人文档排除、目标与来源隔离及单次预算不被适配层扩大。
3. 调用 `scripts/sync.py scan|apply|status`，不在 Claude 提示词中重写采集、路由、审核和幂等规则；主动投递、专用视图、受限扫描的优先级保持一致。
4. 飞书和 Meegle 凭证由运行环境提供，不写入配置、Prompt 或知识文档。
5. Claude 只处理经过公共核心低成本筛选后的少量候选，不得重新读取公司全空间、个人文档或未变化全文。
6. Claude 产生的语义提炼结果仍只能作为“Agent 推断”字段进入审核，不能绕过 Base 审核状态。

适配层的验收标准是：同一配置和同一来源在 Codex 与 Claude 环境产生相同的来源 ID、内容哈希、目标范围和提案 ID，并遵守相同的来源准入、候选数量和 Token 预算。当前 V2 尚未实现真正的模型提炼和代码级 Token 硬预算，适配工作不得把目标能力表述为现状。
